# Raport T-26: formatPLN(kwota) z testami

Issue: #26
PR: #31

## Co zrobiono

- `src/formatPLN.ts` eksportuje `formatPLN(kwota: number): string` → `src/formatPLN.ts`, import w `tests/formatPLN.test.ts`; sprawdza `pnpm typecheck`.
- `1234.5` daje „1 234,50 zł” → separator tysięcy i odstęp przed „zł” to spacja twarda U+00A0, udokumentowane w komentarzu i asercjach testów „formatuje 1234.5 jako „1 234,50 zł” ze spacją twardą” oraz „używa spacji twardej, nie zwykłej”; grupowanie dla 0, 999,99, 1000, 1 234 567,89.
- Kwoty ujemne mają znak minus, zaokrąglenie do 2 miejsc → testy „kwoty ujemne mają znak minus” (ASCII `-`) i „zaokrągla do 2 miejsc po przecinku” (m.in. 1.236 → 1,24, 999.999 → 1 000,00, -1.236 → -1,24).
- NaN i Infinity rzucają TypeError → `Number.isFinite`, test `it.each` dla `NaN`, `Infinity`, `-Infinity`.
- Dodatkowo: kwota zerowa po zaokrągleniu bez minusa (`-0`, `-0.001` → „0,00 zł”) i kwoty ≥ 1e21 bez notacji wykładniczej, oba z testami.

## Decyzje

- Spacja twarda czy zwykła jako separator tysięcy → spacja twarda U+00A0, także przed „zł”, bo kwota nie łamie się między wierszami i tak samo robi `Intl.NumberFormat("pl-PL")`.
- `Intl.NumberFormat` czy własne formatowanie → własne (`toFixed` + regex grupujący), bo `pl-PL` w ICU domyślnie nie grupuje liczb czterocyfrowych (`minimumGroupingDigits: 2`, „1234,50 zł”), a wynik Intl zależy od wersji ICU w Node.
- Znak minus → ASCII `-` (U+002D), a nie U+2212, bo łatwiej go parsować i porównywać.
- Reguła zaokrąglenia → jak `Number.prototype.toFixed(2)`: połówki w górę liczone od dokładnej wartości liczby zmiennoprzecinkowej (np. 0.125 → 0,13, ale 1.005 → 1,00, bo 1.005 w binarnym zapisie jest mniejsze).
- Minus przy kwocie, która po zaokrągleniu wynosi zero → bez minusa („0,00 zł”), bo „-0,00 zł” myli czytelnika.
- Eksport z `src/index.ts` → nie dodany, bo `src/index.ts` nie jest w „Zakresie” issue; funkcja dostępna z `src/formatPLN.ts`.
- Specyfikacji i architektury nie ma w repo (`docs/00-intake/specyfikacja.md`, `docs/04-architektura/architektura.md`), pracowałem z issue. Dodatkowo przeczytane: `src/index.ts`, `tests/smoke.test.ts`, `eslint.config.js`, `vitest.config.ts`, `docs/07-realizacja/T-23.md` (format raportu).

## Drobne uwagi

- `src/index.ts` nie reeksportuje `formatPLN`; do rozważenia osobnym zadaniem, gdy biblioteka dostanie publiczne API.

## Ryzyka

- 1.005 i podobne wartości zaokrąglają się „w dół” przez reprezentację binarną; kwoty wyliczane arytmetyką zmiennoprzecinkową mogą różnić się o grosz od oczekiwań księgowych.
