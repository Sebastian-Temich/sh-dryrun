# Raport T-53: capitalize(text) z testami i przykładem w README

Issue: #53
PR: #NR_PR

## Co zrobiono

- `src/capitalize.ts` eksportuje `capitalize(text: string): string`, a `src/index.ts` ją reeksportuje.
  Test: `tests/capitalize.test.ts`, „jest reeksportowana z punktu wejścia pakietu”.
- „ala ma kota” → „Ala ma kota”, „łódź” → „Łódź” (`toLocaleUpperCase('pl-PL')`). Testy: dwa
  pierwsze przypadki w `tests/capitalize.test.ts`.
- Pozostałe znaki bez zmian („aBC” → „ABC”), pusty tekst → pusty string. Testy: „zostawia pozostałe
  znaki bez zmian”, „daje pusty string dla pustego tekstu”, dodatkowo tekst zaczynający się od wielkiej
  litery, spacji i cyfry.
- `tests/capitalize.test.ts` pokrywa wszystkie przypadki; `pnpm lint`, `pnpm typecheck`, `pnpm test`
  zielone.
- `README.md` ma sekcję „Użycie” z importem `capitalize` z pakietu `sh-dryrun` i wynikami.

## Decyzje

- Co jest „pierwszą literą”, gdy tekst zaczyna się od znaku spoza BMP? → pierwszy punkt kodowy
  (`codePointAt`), żeby nie rozcinać pary surogatów; zgodne z „pozostałe znaki bez zmian”.
- Tekst zaczynający się od spacji lub cyfry → bez zmian (wielka litera tylko dla pierwszego znaku, bez
  szukania pierwszej litery dalej), bo kryterium mówi o pierwszym znaku tekstu, a reszta ma zostać bez
  zmian.
