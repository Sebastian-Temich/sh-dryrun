# Raport T-98: slugify: slug z tekstu (W-01)

Issue: #98
PR: #106

## Co zrobiono

- Eksport z `src/index.ts` w sekcji `// W-01 slug`: linia `export { slugify } from './slugify.js';`.
  `src/slugify.test.ts` importuje z `./index.js`, więc każdy test sprawdza punkt wejścia. Po
  `pnpm build` `dist/index.js` eksportuje `[ 'slugify' ]`.
- W-01/K1: test „W-01/K1: polskie znaki zamienia na łacińskie, małe litery, usuwa interpunkcję”:
  „Zażółć Gęślą Jaźń!” → „zazolc-gesla-jazn”.
- W-01/K2: test „W-01/K2: wielokrotne spacje dają jeden myślnik, bez myślników na końcach”:
  „  wiele   spacji  ” → „wiele-spacji”.
- W-01/K3: test „W-01/K3: zostawia cyfry i usuwa emoji („Łódź 2026 🚀”)”: → „lodz-2026”.
- W-01/K4: test parametryzowany „W-01/K4: %s zamiast tekstu daje TypeError „Oczekiwano tekstu””
  dla liczby, `null`, `undefined`, obiektu i tablicy: `TypeError` z komunikatem „Oczekiwano tekstu”.
- Stany z karty: „Pusty” (pusty tekst i same spacje → `''`), „Częściowy sukces” (cyrylica i emoji
  usuwane), wszystkie polskie litery małe i wielkie, separatory `_`, `--` i twarda spacja ` `.
- Implementacja `src/slugify.ts`: `ł`/`Ł` → `l`, NFD, usunięcie znaków diakrytycznych (`\p{M}`),
  małe litery, każdy ciąg znaków spoza `[a-z0-9]` → jeden myślnik, obcięcie myślników na końcach.

## Testy

- `pnpm vitest run src/slugify.test.ts` (komenda z issue): przed implementacją 12 czerwonych
  („slugify is not a function”), po implementacji 12 zielonych.
- `pnpm test`: zielone, 2 pliki, 14 testów, pokrycie 100% linii i gałęzi.
- `pnpm lint`: zielone.
- `pnpm typecheck`: zielone.
- `pnpm build`: zielone; `node --input-type=module --eval "import('./dist/index.js')…"` daje
  `[ 'slugify' ]` i „zazolc-gesla-jazn”.

## Decyzje

- `src/index.test.ts` (spoza „Zakresu”, test szkieletu z T1) zakładał brak eksportów funkcji i pustą
  linię pod każdą sekcją, więc padał po dodaniu eksportu wymaganego kryterium → zmieniony minimalnie:
  dopuszcza tylko eksporty nazwane z planu (`slugify`, `formatPLN`, `chunk`, `retry`, `kursNBP`,
  `przelicz`) i pod komentarzem sekcji pustą linię albo jeden `export { x } from './plik.js';`.
  Kolejne zadania T3–T7 nie muszą go już zmieniać.
- Karta W-01, P1 („Znaki spoza alfabetu łacińskiego usuwamy; pusty wynik daje pusty slug”, status
  „do potwierdzenia”) → wdrożone zgodnie z proponowaną odpowiedzią, bo potwierdzają ją kryteria K3
  w issue i stany „Pusty” i „Częściowy sukces” karty; nie było potrzeby pytania.
- Litery z diakrytykami spoza polskiego alfabetu (np. „é”, „ü”) → też zamieniane na literę bazową,
  bo wynika to z tego samego rozkładu NFD; karta tego nie zabrania i nie wymaga osobnej obsługi.
