## Decyzje

- Jak opisać „instalację z repo”, skoro `dist/` nie jest w repo, a pakiet nie ma skryptu `prepare`? →
  klon, `pnpm install --frozen-lockfile`, `pnpm build`, potem `pnpm add file:../sh-dryrun` w projekcie
  użytkownika; sprawdzone w projekcie testowym. Instalacja `pnpm add github:…` nie zbudowałaby `dist/`,
  a dodanie `prepare` to zmiana `package.json` spoza zakresu.
- Gdzie w README nowe sekcje? → „Instalacja”, „Użycie”, „Środowiska” po „Zakresie”, przed
  „Uruchomieniem”; pozostałych sekcji (z szablonu) nie zmieniałem, bo są poza zakresem issue.
- Twarda spacja w przykładzie `formatPLN` → w tabeli zapis czytelny „1 234,50 zł” z dopiskiem o U+00A0,
  a w bloku kodu jawny escape `"1 234,50 zł"` (skill `sh-tdd-testy`, punkt 8).
- Numer wydania v0.1 a `version: 0.0.0` w `package.json` → nie zmieniam `package.json` (poza zakresem),
  rozbieżność opisana w „Znanych ograniczeniach” v0.1.md.
- Dodatkowo przeczytane: testy w `tests/`, `src/index.ts`, `src/parseDate.ts`, `package.json`,
  `docs/konfiguracja.md`, `docs/wydanie/DoD.md`, `docs/_szablony/wydanie-techniczna.md`,
  `escalations/E-001.md`, raporty T-75–T-81 (tytuły, numery zadań), `.github/workflows/ci.yml` (nazwy
  kroków), stan issue #79 (zamknięte).
