# Karta funkcji W-03: Kwota w złotych

## Dla właściciela

### Opis

Programista podaje kwotę i dostaje ją zapisaną po polsku: tysiące oddzielone spacją, przecinek przed
groszami, dwa miejsca po przecinku i „zł” na końcu (1234.5 daje „1 234,50 zł”). Spacja nie łamie się
na końcu wiersza.

### Przebieg

1. Programista importuje funkcję formatPLN z pakietu.
2. Wywołuje ją z kwotą.
3. Dostaje tekst kwoty albo komunikat błędu.

### Stany ekranu

| Stan | Kiedy | Co widzi użytkownik |
|---|---|---|
| Pusty | Kwota zero | „0,00 zł” (także dla minus zera) |
| W trakcie | Formatowanie | nie dotyczy: wynik natychmiast |
| Sukces | Zwykła kwota | Np. „1 234,50 zł”, „-12,30 zł”, „999,00 zł” |
| Częściowy sukces | | nie dotyczy: wynik jest jeden |
| Błąd w danych | Nie-liczba albo nieskończoność | Błąd typu z komunikatem „formatPLN: kwota musi być skończoną liczbą” |
| Błąd po naszej stronie | | nie dotyczy: brak usług zewnętrznych |
| Za dużo prób albo brak dostępu | | nie dotyczy: brak limitów i uprawnień |

### Poza zakresem

- Inne waluty i zapis słowny kwoty.
- Dokładność groszy dla kwot większych niż bezpieczna liczba całkowita.

### Do potwierdzenia

| Nr | Pytanie albo założenie | Proponowana odpowiedź | Status |
|---|---|---|---|
| Z3 | Bardzo duże kwoty | Formatowane bez gwarancji groszy, bez błędu | do potwierdzenia |
| P4 | Separator tysięcy | Twarda spacja, grupowanie od 1000 | potwierdzone 2026-11-10 |
| P5 | Zaokrąglenie | Połówki od zera na wartości dziesiętnej (1,005 daje 1,01 zł) | potwierdzone 2026-11-10 |

## Dla wykonawcy

### Kryteria akceptacji

- W-03/K1: Given `src/formatPLN.ts`, when importuję `formatPLN`, then sygnatura to `formatPLN(kwota: number): string`.
- W-03/K2: Given 1234.5, when `formatPLN`, then `"1 234,50 zł"` (twarda spacja U+00A0 jako separator tysięcy i przed „zł”; grupowanie także dla liczb 4-cyfrowych, nie `Intl` pl-PL).
- W-03/K3: Given -1234.5, when `formatPLN`, then `"-1 234,50 zł"`; given -0 i -0.001, then `"0,00 zł"`.
- W-03/K4: Given 1.005, 2.675 i 0.125, when `formatPLN`, then „1,01 zł”, „2,68 zł”, „0,13 zł” (połówki od zera na wartości dziesiętnej, np. przez `toPrecision`/`Number.EPSILON`).
- W-03/K5: Given `NaN`, `Infinity`, `-Infinity`, when `formatPLN`, then rzuca `TypeError`.

### Design i ADR

Nie dotyczy: biblioteka bez UI, bez ADR. Moduł `src/formatPLN.ts`, testy `tests/formatPLN.test.ts`.
