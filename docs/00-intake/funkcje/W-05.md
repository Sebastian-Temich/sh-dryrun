# Karta funkcji W-05: Kurs waluty z tabeli NBP

## Dla właściciela

### Opis

Programista podaje kod waluty, np. EUR, i dostaje średni kurs z najnowszej tabeli A Narodowego Banku
Polskiego razem z datą tabeli. Funkcja korzysta z publicznej usługi NBP, która nie wymaga konta ani
klucza. To jedyna funkcja biblioteki, która łączy się z usługą zewnętrzną.

### Przebieg

1. Programista wywołuje funkcję z kodem waluty.
2. Funkcja sprawdza kod (trzy litery) i pyta usługę NBP o kurs.
3. Funkcja sprawdza odpowiedź NBP (czy jest kurs dodatni i data).
4. Programista dostaje kurs i datę tabeli albo błąd z opisem.

### Stany ekranu

| Stan | Kiedy | Co widzi użytkownik |
|---|---|---|
| Pusty | nie dotyczy: zawsze jest kod waluty | — |
| W trakcie | Czekanie na usługę NBP, najwyżej 5 s | Oczekiwanie na wynik |
| Sukces | NBP zwraca kurs | Kurs i data tabeli |
| Częściowy sukces | nie dotyczy: kurs jest albo go nie ma | — |
| Błąd w danych | Kod nie ma trzech liter albo nie ma go w tabeli | Błąd: „Nieznana waluta: KOD” |
| Błąd po naszej stronie | NBP nie odpowiada w 5 s, zwraca błąd albo odpowiedź bez kursu | Błąd: „Usługa NBP niedostępna” |
| Za dużo prób albo brak dostępu | nie dotyczy: jedno zapytanie na wywołanie, bez ponawiania | — |

### Reguły biznesowe

- R1: Kurs pochodzi wyłącznie z tabeli A NBP (kursy średnie), najnowszej opublikowanej.
- R2: Wielkość liter kodu nie ma znaczenia; wynik ma zawsze kod wielkimi literami.
- R3: Jedno wywołanie to jedno zapytanie do NBP, bez ponawiania i bez zapamiętywania wyniku.
- R4: Odpowiedź NBP bez dodatniego kursu albo bez daty traktujemy jak niedostępność usługi.

### Poza zakresem

- Kursy archiwalne i tabele B i C.
- Zapamiętywanie kursów między wywołaniami.
- Automatyczne ponawianie (programista może użyć W-04).

### Do potwierdzenia

| Nr | Pytanie albo założenie | Proponowana odpowiedź | Status |
|---|---|---|---|
| P5 | Które waluty | Wszystkie z tabeli A NBP, kod trzyliterowy | do potwierdzenia |
| Z1 | Limit czasu odpowiedzi NBP | 5 s | do potwierdzenia |

## Dla wykonawcy

### Wejście

Programista (bez ról). Punkt wejścia: eksport nazwany `kursNBP(kod: string, opcje?: { fetch?: typeof fetch; timeoutMs?: number }): Promise<{ kod: string; kurs: number; data: string }>` z `src/index.ts`. Stan początkowy: brak, funkcja bezstanowa.

### Pola i walidacja

| Pole | Kierunek | Typ i format | Wymagane | Limit i walidacja | Komunikat błędu |
|---|---|---|---|---|---|
| `kod` | wejście | string, `/^[A-Za-z]{3}$/` | tak | dokładnie 3 litery | `Nieznana waluta: KOD` |
| `opcje.fetch` | wejście | funkcja zgodna z `fetch` | nie | domyślnie globalny `fetch` | — |
| `opcje.timeoutMs` | wejście | liczba całkowita > 0 | nie | domyślnie 5000 | `RangeError` „Limit czasu musi być dodatni” |
| `rates[0].mid` | odpowiedź NBP | number | tak | > 0, skończona | `Usługa NBP niedostępna` |
| `rates[0].effectiveDate` | odpowiedź NBP | string `RRRR-MM-DD` | tak | format daty | `Usługa NBP niedostępna` |
| wynik | wyjście | `{ kod, kurs, data }` | — | `kod` wielkimi literami | — |

Dane: brak danych osobowych, nic nie jest zapisywane; adres
`https://api.nbp.pl/api/exchangerates/rates/a/{KOD}/?format=json`, nagłówek `Accept: application/json`.

### Odpowiedzi i błędy

| Sytuacja | Kod odpowiedzi | Stan ekranu z części dla właściciela | Log (bez danych osobowych) |
|---|---|---|---|
| Kurs znaleziony | 200 NBP | Sukces | brak logów (biblioteka) |
| Kod spoza tabeli | 404 NBP | Błąd w danych: `NieznanaWalutaError` | brak |
| Zły format kodu | brak zapytania | Błąd w danych: `NieznanaWalutaError` | brak |
| Błąd NBP | 400, 5xx NBP | Błąd po naszej stronie: `NbpNiedostepneError` z `cause` | brak |
| Limit czasu | AbortController po `timeoutMs` | Błąd po naszej stronie: `NbpNiedostepneError` | brak |
| JSON bez `rates[0].mid` > 0 albo daty | 200 NBP | Błąd po naszej stronie: `NbpNiedostepneError` | brak |

### Dostępność

Nie dotyczy: biblioteka bez interfejsu. Komunikaty błędów po polsku w `message`.

### Przypadki brzegowe

- Kod z małymi literami i spacjami na końcach: spacje to błąd formatu, małe litery dozwolone (R2).
- Dwa równoległe wywołania: każde ma własne zapytanie i własny `AbortController`.
- Odpowiedź z kursem 0, ujemnym, `NaN` albo tekstem: `NbpNiedostepneError`.
- Odpowiedź niebędąca JSON-em: `NbpNiedostepneError`.
- Testy bez sieci: wyłącznie atrapa `opcje.fetch` albo `vi.stubGlobal("fetch")`; fałszywy zegar dla limitu czasu.

### Kryteria akceptacji

- W-05/K1: Given atrapa fetch z odpowiedzią tabeli A dla EUR (mid 4.3, effectiveDate 2026-11-10), when `kursNBP("EUR")`, then `{ kod: "EUR", kurs: 4.3, data: "2026-11-10" }`.
- W-05/K2: Given kod „XYZ” i odpowiedź 404 NBP, when `kursNBP`, then `NieznanaWalutaError` „Nieznana waluta: XYZ”.
- W-05/K3: Given atrapa fetch bez odpowiedzi przez 5 s, when `kursNBP`, then `NbpNiedostepneError` „Usługa NBP niedostępna” (fałszywy zegar).
- W-05/K4: Given kod „eur”, when `kursNBP`, then zapytanie o adres z „EUR” i wynik z `kod: "EUR"`.
- W-05/K5: Given kod „EU” albo „EURO”, when `kursNBP`, then `NieznanaWalutaError` bez wywołania fetch.
- W-05/K6: Given odpowiedź 200 z `mid: 0` albo bez `effectiveDate`, when `kursNBP`, then `NbpNiedostepneError`.
- W-05/K7: Given odpowiedź 503, when `kursNBP`, then `NbpNiedostepneError` z `cause` zawierającym status.

### Design i ADR

Nie dotyczy design: biblioteka bez interfejsu. ADR w 04-plan: integracja z API NBP (limit czasu,
obsługa błędów, testy bez sieci przez wstrzykiwany `fetch`).
