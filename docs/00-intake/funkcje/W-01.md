# Karta funkcji W-01: Suma dwóch liczb

## Dla właściciela

### Opis

Programista podaje dwie liczby i dostaje ich sumę. Gdy któraś z nich nie jest zwykłą liczbą
(na przykład „nie-liczba” albo nieskończoność), funkcja zgłasza błąd zamiast zwracać bezsensowny wynik.

### Przebieg

1. Programista importuje funkcję sum z pakietu.
2. Wywołuje ją z dwiema liczbami.
3. Dostaje sumę albo komunikat błędu.

### Stany ekranu

| Stan | Kiedy | Co widzi użytkownik |
|---|---|---|
| Pusty | Brak argumentów | nie dotyczy: biblioteka bez ekranu, kompilator wymaga dwóch liczb |
| W trakcie | Obliczenie | nie dotyczy: wynik natychmiast |
| Sukces | Dwie zwykłe liczby | Suma, np. 2 i 3 dają 5 |
| Częściowy sukces | | nie dotyczy: wynik jest jeden |
| Błąd w danych | Nie-liczba albo nieskończoność | Błąd typu z komunikatem „sum: argumenty muszą być skończonymi liczbami” |
| Błąd po naszej stronie | | nie dotyczy: brak usług zewnętrznych |
| Za dużo prób albo brak dostępu | | nie dotyczy: brak limitów i uprawnień |

### Poza zakresem

- Sumowanie więcej niż dwóch liczb i list.
- Dokładna arytmetyka dziesiętna (ułamki liczone zwykłą arytmetyką komputera).

### Do potwierdzenia

| Nr | Pytanie albo założenie | Proponowana odpowiedź | Status |
|---|---|---|---|
| Z1 | Wynik sumy ułamków | Zwykła arytmetyka liczb zmiennoprzecinkowych, testy z tolerancją | do potwierdzenia |

## Dla wykonawcy

### Kryteria akceptacji

- W-01/K1: Given `src/sum.ts`, when importuję `sum`, then sygnatura to `sum(a: number, b: number): number`.
- W-01/K2: Given liczby dodatnie, ujemne, zero i ułamki, when wywołuję `sum`, then wynik jest poprawny (ułamki przez `toBeCloseTo`).
- W-01/K3: Given `NaN`, `Infinity` albo `-Infinity` w dowolnym argumencie, when wywołuję `sum`, then rzuca `TypeError`.

### Design i ADR

Nie dotyczy: biblioteka bez UI, bez ADR. Moduł `src/sum.ts`, testy `tests/sum.test.ts`.
